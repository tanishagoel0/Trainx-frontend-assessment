# Blinkit Landing Page Clone 🛒

A pixel-focused, responsive clone of the **Blinkit landing page**, developed as a frontend assignment using HTML5 and CSS3.

The project focuses on recreating Blinkit's user interface while demonstrating frontend fundamentals, responsive layouts, and creative CSS-only interactions.

## 🚀 Features

### 1. Homepage Sections
- Responsive header with Blinkit logo, delivery information, search bar, login, and cart.
- Promotional hero banner.
- Three promotional cards:
  - Pharmacy
  - Pet Care
  - Baby Care
- Product category grid.
- Footer with useful links, app download badges, and social media icons.

### 2. CSS-Only Interactions
This project demonstrates interactive UI elements without JavaScript.

- **Popup Modals:** Clicking a promotional card or category opens a popup using the CSS `:target` selector.
- **Product Listings:** Six categories display product lists with filter chips.
- **Cart Interaction:** ADD buttons update the cart using HTML checkboxes, CSS counters, and the `:has()` selector.
- **Live Cart Display:** Displays the selected item count and calculated total using CSS-only techniques.

### 3. Responsive Design
- Desktop, tablet, and mobile-friendly layouts.
- Tested across screen widths from **320px to 1920px**.
- Uses CSS media queries to adapt layouts.
- No horizontal scrolling or overlapping elements.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure and content |
| CSS3 | Styling and visual design |
| Flexbox | Navigation and component alignment |
| CSS Grid | Product and category layouts |
| CSS Media Queries | Responsive design |
| CSS Variables | Consistent colors and styling |
| CSS `:target` | Popup interactions |
| CSS `:has()` | Conditional styling and cart interactions |
| CSS Counters | Cart item counting |

**No JavaScript or CSS frameworks are used.**

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder

```bash
cd blinkit-clone
```

### 3. Open the website

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a local development preview.
